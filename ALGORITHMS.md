# Kinetic Routines — Algorithms

Exact step-by-step pseudocode from Kotlin sources. Magic numbers and quirks preserved.  
Companion: [SPEC.md](SPEC.md), [STRINGS.md](STRINGS.md).  
Golden fixtures: [`golden/`](golden/) (generated by `GoldenFixturesDumpTest`).

Date keys are ISO `yyyy-MM-dd` via `DateCodec` (`LocalDate.toString()`).  
`createdAt` millis → local date with `ZoneId.systemDefault()`.

## 1. Habit start date

**File:** `domain/analytics/HabitAnalyticsEngine.kt` — `habitStartDate`

```
habitStartDate(habit, records):
  createdDate ← millisToDate(habit.createdAt)   // system zone
  earliestLog ← min(parse(record.dateString) for records) or null
  if earliestLog ≠ null AND earliestLog < createdDate:
    return earliestLog          // backfills pull start earlier
  else:
    return createdDate
```

**Quirk:** Days before start are never walked → never penalized (EMA starts at 0).

## 2. Momentum EMA

**File:** `HabitAnalyticsEngine.calculateAnalytics` / `momentumHistory` / `calculateMomentumPercent`

### Day credit

```
dayCredit(record):
  if record.isCompleted → 1.0
  else if record.isFloorSustained → 0.65
  else → 0.0
```

### Rest freeze

```
isRest(date) ← restShieldEnabled AND habit.isRestDay(date.dayOfWeek.value)  // ISO Mon=1..Sun=7
isDone(date) ← record exists AND (isCompleted OR isFloorSustained)

shouldFreeze(date) ← isRest(date) AND NOT isDone(date)
```

**Quirk:** Logging on a rest day **does** update EMA (freeze only when rest **and** not done).  
If `restShieldEnabled == false`, rest bits are ignored (normal miss/complete/floor).

### EMA walk (`calculateAnalytics`)

```
today ← clock.today()
startDate ← habitStartDate(habit, records)
windowStart ← max(today − 90 days, startDate)
damping ← 0.93
strength ← 0.0
progression ← []   // last 30 days of (dateString, strength*100)

for date from windowStart through today inclusive:
  if shouldFreeze(date):
    // no update — freeze
  else:
    v ← dayCredit(rec(date))
    strength ← strength * damping + (1 − damping) * v
  if date ≥ today − 30 days:
    progression.append(format(date), strength * 100)

strengthPercent ← round(strength * 100).coerceIn(0, 100)
```

### `calculateMomentumPercent`

```
last ← momentumHistory(..., days=1).last
if last == null → 0
else → round(last).coerceIn(0, 100)
```

Must match `calculateAnalytics.habitStrengthPercent` for the same inputs.

### `momentumHistory(days)`

```
windowStart ← today − (days − 1)
strength ← 0
date ← max(today − 90, startDate)
// Warm EMA until day before visible window:
while date < windowStart AND date ≥ startDate:
  apply same freeze/credit update
  date ← date + 1
if date < startDate: date ← startDate
history ← array of `days` nulls
while date ≤ today:
  if date ≥ startDate:
    apply freeze/credit update
    offset ← daysBetween(windowStart, date)
    if offset in [0, days): history[offset] ← strength * 100   // unrounded Float
  date ← date + 1
return history   // slots before startDate stay null
```

## 3. Trajectory label

**File:** `HabitAnalyticsEngine.calculateAnalytics`

```
lastWeek ← if progression.size ≥ 8 then progression[size − 8].second else 0.0
           // ≈ 7 days ago in the 30-day progression; unrounded Float

when:
  strengthPercent > lastWeek + 3  → "Accelerating"
  strengthPercent < lastWeek − 3  → "Rebuilding"
  strengthPercent ≥ 70            → "Steady High"
  else                            → "Forming Routine"
```

**Quirk:** Compares **rounded Int** percent to **unrounded Float** history. Short progression → `lastWeek = 0` → easy Accelerating after first logs.

## 4. Current streak

```
currentStreak ← 0
cursor ← today
// Grace: unlogged active today does not break streak
if NOT isDone(today) AND NOT isRest(today):
  cursor ← today − 1 day

while cursor ≥ startDate:
  if isDone(cursor): currentStreak++; cursor ← cursor − 1
  else if isRest(cursor): cursor ← cursor − 1   // preserve, do not count
  else: break                                  // miss
```

Rest today while not done: loop skips today (no break, no increment).

## 5. Best streak

```
bestStreak ← 0
temp ← 0
scan ← max(today − 180 days, startDate)
while scan ≤ today:
  if isDone(scan): temp++; bestStreak ← max(bestStreak, temp)
  else if isRest(scan): // no-op — bridge, neither count nor reset
  else: temp ← 0
  scan ← scan + 1
bestStreak ← max(bestStreak, currentStreak)
```

**Quirk:** History older than 180 days is ignored for best (unless current streak is larger).

## 6. Heatmap cell state

**File:** `HabitAnalyticsEngine.calculateAnalytics`

```
firstDayOfWeek ← Monday if weekStartsOnMonday else Sunday
heatStart ← today − 139 days
while heatStart.dayOfWeek ≠ firstDayOfWeek:
  heatStart ← heatStart − 1 day

cells ← []
h ← heatStart
repeat 140 times:                         // 20 weeks × 7
  r ← rec(h)
  beforeCreation ← h < startDate
  state ← when first match:
    beforeCreation                         → NONE
    r.isCompleted                          → FULL_COMPLETED
    r.isFloorSustained                     → FLOOR_SUSTAINED
    isRest(h)                              → REST_SHIELD
    r ≠ null AND r.frictionTag ≠ null      → MISSED
    else                                   → NONE
  tooltip ← when state:
    FULL_COMPLETED  → "{date}: Completed Target"
    FLOOR_SUSTAINED → "{date}: Sustained Minimum Floor"
    REST_SHIELD     → "{date}: Rest Day Shield"
    MISSED          → "{date}: Skipped ({frictionTag|Unspecified})"
    NONE            → "{date}: No entry"
  cells.append(HeatmapCell(date, dayOfWeekIso, state, tooltip))
  h ← h + 1 day
```

**Critical quirk:** A miss with **no record** (or record without `frictionTag`) is `NONE`, not `MISSED`.  
Rest + completed log → FULL/FLOOR, not REST.

## 7. Day-of-week rates

```
dayCounts[7] ← 0; dayCompleted[7] ← 0   // index 0=Mon .. 6=Sun
d ← max(today − 60 days, startDate)
while d ≤ today:
  idx ← d.dayOfWeek.value − 1
  dayCounts[idx]++
  if isDone(d): dayCompleted[idx]++
  d ← d + 1
dayRates[i] ← dayCompleted[i] / dayCounts[i] if dayCounts[i] > 0 else 0.0
```

**Quirk:** Rest days without a log still inflate the denominator (lower that DOW’s rate).

## 8. Logging rules

**File:** `data/repository/LogRepository.kt`

### Effective floor (runtime)

```
floorOf(habit) ← habit.floorValue ?: (habit.targetValue * 0.25)
```

**Quirk:** Settings `defaultFloorPercent` is an **editor placeholder only**. Null `floorValue` always uses **0.25** at log time, ignoring Settings.

### Day-click routing (`KineticViewModel.handleDayClick`)

| Modality | Tap | Long-press |
|----------|-----|------------|
| YES_NO | `toggleHabitForDate` | QuickLog |
| TALLY | `logTallyIncrement` (+1) | QuickLog |
| TIMER | opens QuickLog | QuickLog (+ timer → `logDurationSeconds`) |
| NUMERIC | if not already done/floor → `toggleHabitForDate` (full target); else QuickLog | QuickLog |

### `toggleHabitForDate`

```
existing ← getLog(habitId, date)
if existing == null → insert completedRecord
else if existing.isCompleted → delete log
else → upgrade to completedRecord (e.g. floor → target)
```

### `setCompletedForDate` (notifications)

```
if existing?.isCompleted → no-op
else → upsert completedRecord
```

### `completedRecord`

```
isCompleted ← true
isFloorSustained ← false
numericValue ← habit.targetValue
if TIMER: durationSeconds ← (target * 60).toInt()
if TALLY: tallyCount ← target.toInt() else max(existing.tallyCount, 1)
```

### `logFloorSustainForDate`

```
if existing?.isCompleted → no-op
else:
  isCompleted ← false; isFloorSustained ← true
  numericValue ← floorOf(habit)
  if TIMER: durationSeconds ← (floor * 60).toInt()
  if TALLY: tallyCount ← floor.toInt().coerceAtLeast(1)
```

### `logNumericProgress(amount)`

```
if amount ≤ 0 → delete log; return
isMet ← amount ≥ target
isCompleted ← isMet
isFloorSustained ← !isMet AND amount ≥ floorOf
numericValue ← amount
// TIMER/TALLY also mirror amount into durationSeconds / tallyCount
```

### `logTallyIncrement`

```
next ← (existing.tallyCount ?: 0) + 1
isMet ← next ≥ target
isCompleted ← isMet
isFloorSustained ← !isMet AND next ≥ floorOf
tallyCount ← next; numericValue ← next
```

### `logDurationSeconds(durationSec)`

```
if durationSec ≤ 0 → return
totalSec ← (existing.durationSeconds ?: 0) + durationSec
isMet ← totalSec ≥ (target * 60).toInt()
isCompleted ← isMet
isFloorSustained ← !isMet AND totalSec ≥ (floorOf * 60).toInt()
durationSeconds ← totalSec; numericValue ← totalSec / 60.0
```

### `logFrictionTag`

Sets/keeps `frictionTag` + `notes`; does **not** clear or set completed/floor flags.

### Friction tags (UI)

`Low Energy`, `Time Crunch`, `Travel / Away`, `Distraction`

## 9. NextReminderCalculator

**File:** `notification/NextReminderCalculator.kt`

### Habit reminder

```
nextFire(habit, from: LocalDateTime):
  hour ← habit.reminderHour ?: return null
  minute ← habit.reminderMinute ?: return null
  for offset in 0..8:                    // today + 8 days
    date ← from.toLocalDate() + offset days
    iso ← date.dayOfWeek.value           // Mon=1..Sun=7
    if NOT habit.isReminderEnabledForDay(iso): continue
    if habit.isRestDay(iso): continue
    candidate ← date.atTime(hour, minute)
    if candidate.isAfter(from): return candidate   // strictly after
  return null
```

Masks: bit `(iso − 1)`; `reminderDaysMask` default `127` (all days); `restDaysMask` default `0`.

`isReminderEnabledForDay`: false if hour/minute null; else mask bit.

### Evening digest

```
nextDigestFire(hour, from):
  todayAt ← from.toLocalDate().atTime(hour.coerceIn(0,23), 0)
  if todayAt.isAfter(from) → todayAt else todayAt + 1 day
```

## 10. Effective floor (settings vs runtime)

| Layer | Formula |
|-------|---------|
| Settings `defaultFloorPercent` | default **25**; UI chips 20/25/33/50; stored `coerceIn(1,100)` |
| Editor placeholder | `target * defaultFloorPercent / 100` (suggestion only) |
| Saved habit | blank floor → `floorValue = null` |
| Runtime `floorOf` | `floorValue ?: target * 0.25` |

## 11. Sort

**File:** `ui/viewmodel/KineticViewModel.kt` — `sortHabitCards`  
**Modes:** `HabitSortMode` in `SettingsRepository`

```
sortHabitCards(cards, mode):
  MANUAL → cards unchanged (DB orderIndex order)
  MOMENTUM_DESCENDING → sort by momentumPercent DESC, then orderIndex ASC
  MOMENTUM_ASCENDING → sort by momentumPercent ASC, then orderIndex ASC
```

**Quirk:** Ties always use ascending `orderIndex` → ascending is **not** reverse of descending.

```
nextMomentum():
  MANUAL | ASCENDING → DESCENDING
  DESCENDING → ASCENDING

fromStored(raw):
  "MOMENTUM_DESCENDING" | legacy "MOMENTUM" → DESCENDING
  "MOMENTUM_ASCENDING" → ASCENDING
  else → MANUAL
```

## 12. Nudge selection

**File:** `ui/viewmodel/KineticViewModel.kt` — `buildInAppNudges`

```
if habits.isEmpty() → []

todayStr ← format(today)
doneToday ← { habitId | record.dateString == todayStr AND (completed OR floor) }
stackById ← stacks by id

// Rest check for pending uses habit.restDaysMask ONLY (no Settings restShield flag)

// Slide 1 — today-momentum (MOMENTUM_BOOST)
pendingToday ← first habit where id ∉ doneToday AND NOT isRestDay(today)
title ← "Today's Momentum"
if pendingToday ≠ null:
  subtitle ← "{title} is not logged yet today. A floor log still counts."
  actionLabel ← "Log floor"
  target ← pendingToday.id
else:
  subtitle ← "Everything due today is logged — today's Momentum is protected. Nice work."
  actionLabel ← "View habit"
  target ← habits.first().id

// Slide 2 — momentum-progress (INSIGHT)
strongest ← habit with max momentumPercents[id] ?: 0
title ← "Momentum builds day by day"
if strongest ≠ null AND percent > 0:
  subtitle ← "{title} is your strongest habit at {n}%. A target day adds about 7% — consistency compounds."
else:
  subtitle ← "A target day adds about 7%. Seven target days in a row reach roughly 40%, and a floor day still earns 65% of a target."
actionLabel ← "View habit"; target ← strongest?.id ?: habits.first().id

// Slide 3 — rest-shield (REST_SHIELD)
restTomorrow ← first habit with isRestDay(tomorrow)
if restTomorrow ≠ null:
  title ← "Rest shield tomorrow"
  subtitle ← "{title} has a scheduled rest day tomorrow — decay stays frozen."
else:
  title ← "Rest days protect Momentum"
  subtitle ← "Schedule rest days in a habit's editor and Momentum freezes on those days — no gain, no loss, streak preserved."
actionLabel ← "View habit"; target ← restTomorrow?.id ?: habits.first().id

// Slide 4 — routine-stacks (STACK_PRIMED)
stackPending ← first habit with routineStackId ≠ null AND id ∉ doneToday
if stackPending ≠ null:
  stackName ← stackById[id]?.name ?: "Your stack"   // title; body uses "your stack"
  title ← "{stackName} is ready"
  subtitle ← "{habit} is next in {name|your stack} and not yet logged today."
  actionLabel ← "Open habit"
else:
  title ← "Stack habits into routines"
  subtitle ← "Group related habits into a routine stack in the habit editor, so finishing one habit cues the next."
  actionLabel ← "View habit"

slides ← [today, progress, rest, stack]

// Optional slide 5 — insight-friction
frictionCount ← count(records where frictionTag ≠ null)
if frictionCount > 0:
  title ← "Friction logged {n} time" | "Friction logged {n} times"
  subtitle ← "Open a habit's analytics to see what most often blocks you."
  actionLabel ← "Review habits"; target ← habits.first().id
  append slide

return slides
```

Dismissals: key `id@yyyy-MM-dd`; bare legacy ids do not match.
